# 一念 · Xiu Xin

东方禅意佛学竖滑阅读原型（《般若波罗蜜多心经》完整 260 字九屏 + 《金刚经》核心九屏 + 《地藏经》核心九屏 + 《药师经》核心九屏，共 36 屏）。

## 核心体验

- **一屏一念竖滑**：借壳竖屏滑动肌肉记忆，零启动摩擦开启《心经》《金刚经》《地藏经》《药师经》阅读（支持单经精读与四经合流）；朱砂色标识核心偈句，配合左侧极简节号标尺与宣纸/静夜双主题。
- **轻触解经抽屉**：轻触经文即可唤出极简专刊式研经层（白话释义、梵文词源、深解义理、关联经句），以及防断章取义的「全经上下文」、锁屏组件预览、可下载禅意日签海报与自动禅滑。
- **心境发现与无压修行**：支持关键词与此刻心境探索，配备无断签惩罚的静读计数与「初入」共修计划。

## 本地运行

纯原生静态页面，无需构建依赖：

```bash
python3 -m http.server 8766
```

在浏览器访问 `http://127.0.0.1:8766/` 即可体验。
