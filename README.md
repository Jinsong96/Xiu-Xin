# 一念 · Xiu Xin

东方禅意佛学竖滑阅读原型（《般若波罗蜜多心经》10 屏完整 260 字 + 《金刚经》20 屏 + 《地藏经》16 屏 + 《药师经》16 屏，内置 62 屏经典名句，支持用户自定义上传经文）。

## 核心体验

- **一屏一念竖滑**：借壳竖屏滑动肌肉记忆，零启动摩擦开启《心经》《金刚经》《地藏经》《药师经》及自建经卷阅读（支持单经精读与全部合流）；朱砂色标识核心偈句，配合左侧智能节号标尺与宣纸/静夜双主题。
- **发现瀑布流**：采用小红书式双列瀑布流信息流，融合宣纸金句、典故公案、一语点破与梵文词源四类卡片，支持心境标签筛选、即时红心收藏与关键词搜索。
- **自定义经文上传**：支持本地 `.txt` / `.md` 导入或粘贴经文正文，提供按换行/按句号智能分屏与实时预览，自动融入经流阅读、上下文跳转与全站研经体系。
- **轻触解经抽屉**：轻触经文即可唤出极简专刊式研经层（白话释义、梵文词源、深解义理、关联经句），以及「全经上下文」、锁屏组件预览、可下载禅意日签海报与自动禅滑。

## 本地运行

纯原生静态页面，无需构建依赖：

```bash
python3 -m http.server 8769
```

在浏览器访问 `http://127.0.0.1:8769/` 即可体验。
